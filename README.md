# 🐍 Top 10 Python Beginner Practice Questions

Welcome to my Python learning repository! 🚀

This repository contains beginner-friendly Python practice questions and examples designed to strengthen fundamental programming concepts through hands-on coding.

## 📚 Topics Covered

- **For Loops** – Understanding iteration using `for` loops.
- **Range Function** – Working with Python's `range()` function.
- **Lists** – Iterating through lists and accessing elements.
- **Multiplication Tables** – Generating multiplication tables using loops.
- **Dictionaries** – Creating and accessing dictionary data.
- **Dictionary Updates** – Modifying existing dictionary values.
- **Dictionary Keys** – Accessing dictionary keys.
- **Dictionary Values** – Accessing dictionary values.
- **Key-Value Pairs** – Iterating through dictionaries.
- **Practical Examples** – Working with country names and capitals.
